# راهنمای نصب «سامانه مالی لنج | LENJ Exchange Manager»

## ۱. پیش‌نیاز سیستم

- ویندوز ۱۰ یا ۱۱، نسخهٔ ۶۴ بیتی (x64).
- برای **اجرای** برنامه هیچ پیش‌نیازی لازم نیست؛ فایل اجرایی «خودکفا» (self-contained) است و .NET را داخل خود دارد.
- برنامه کاملاً آفلاین کار می‌کند و به اینترنت نیاز ندارد.

## ۲. روش اول: نصب با فایل Setup

1. فایل `LenjExchange-Setup-<نسخه>.exe` را اجرا کنید.
2. اگر ویندوز پیام **Windows protected your PC** (SmartScreen) نشان داد، روی **More info** و سپس **Run anyway** بزنید. این پیام به این دلیل است که فایل نصب امضای دیجیتال (Code Signing) ندارد.
3. مراحل نصب را دنبال کنید. برنامه در `C:\Program Files\LenjExchange` نصب می‌شود و میان‌بر آن در منوی Start (و در صورت انتخاب، روی دسکتاپ) ساخته می‌شود.
4. در منوی Start یک میان‌بر هم برای باز کردن **پوشهٔ داده‌ها** وجود دارد.

> حذف برنامه (Uninstall) **داده‌ها را پاک نمی‌کند**. پایگاه داده، پیوست‌ها و پشتیبان‌ها در پوشهٔ کاربر باقی می‌مانند.

## ۳. روش دوم: ساختن برنامه از روی کد

### ۳-۱. نصب خودکار ابزارها (پیشنهادی)

در پوشهٔ `installer\windows-setup` روی `Install-Prerequisites.cmd` دوبار کلیک کنید. این اسکریپت Git، .NET 8 SDK و Inno Setup 6 را (در صورت نبودن) نصب می‌کند، تست‌ها را اجرا می‌کند و EXE و فایل Setup را می‌سازد. جزئیات در `installer/windows-setup/README.fa.md` آمده است.

### ۳-۲. ساخت دستی

پیش‌نیاز: .NET 8 SDK و (برای ساخت Setup) Inno Setup 6.

در PowerShell در پوشهٔ اصلی پروژه:

```powershell
powershell -ExecutionPolicy Bypass -File installer\publish.ps1
```

- خروجی EXE: `artifacts\publish\LenjExchange.exe`
- خروجی Setup: `installer\Output\LenjExchange-Setup-<نسخه>.exe`
- گزینهٔ `-SkipTests` اجرای تست‌ها را رد می‌کند.
- اگر Inno Setup نصب نباشد، فقط EXE ساخته می‌شود.

روی لینوکس/مک فقط EXE قابل ساخت است (Setup نه):

```bash
./installer/publish.sh            # SKIP_TESTS=1 برای رد کردن تست‌ها
```

## ۴. محل داده‌ها

| مورد | مسیر پیش‌فرض |
|---|---|
| پایگاه داده (SQLite) | `%LOCALAPPDATA%\LenjExchange\Data\lenj.db` |
| پیوست‌ها | `%LOCALAPPDATA%\LenjExchange\Attachments` |
| پشتیبان‌ها | `%LOCALAPPDATA%\LenjExchange\Backups` |
| گزارش‌های خطا (لاگ) | `%LOCALAPPDATA%\LenjExchange\Logs` |
| PDF رسیدها | `Documents\LenjExchange\Receipts` |
| گزارش‌های خروجی | `Documents\LenjExchange\Reports` |

مسیر رسیدها، گزارش‌ها و پشتیبان‌ها از صفحهٔ **تنظیمات** قابل تغییر است.

## ۵. اجرای اول

1. برنامه را باز کنید. چون هنوز کاربری وجود ندارد، صفحهٔ **ساخت مدیر سیستم** نمایش داده می‌شود.
2. نام کاربری، نام نمایشی و رمز عبور (حداقل ۸ کاراکتر) را وارد کنید. این کاربر نقش **مدیر (Admin)** دارد.
3. پس از ورود، به صفحهٔ **تنظیمات** بروید و مشخصات شرکت، الگوی شمارهٔ رسید و مسیرها را بررسی کنید.
4. از صفحهٔ **کاربران** برای اپراتورها حساب جداگانه بسازید.

## ۶. پشتیبان‌گیری

- از صفحهٔ **پشتیبان‌گیری** می‌توانید پشتیبان کامل (پایگاه داده + پیوست‌ها، در یک فایل ZIP) بسازید و صحت آن را بررسی کنید.
- پشتیبان‌ها را مرتباً روی یک دیسک یا فلش جداگانه کپی کنید.
- بازگردانی پشتیبان فقط برای کاربر دارای مجوز «بازگردانی پشتیبان» ممکن است؛ پیش از بازگردانی، از وضعیت فعلی به‌طور خودکار پشتیبان گرفته می‌شود و پس از آن باید دوباره وارد شوید.

## ۷. مشکلات رایج

- **برنامه باز نمی‌شود:** فایل‌های پوشهٔ `Logs` را بررسی کنید و برای پشتیبانی ارسال کنید.
- **چاپ کار نمی‌کند:** دکمهٔ چاپ از برنامهٔ پیش‌فرض PDF ویندوز استفاده می‌کند. یک نمایشگر PDF (مثلاً Adobe Reader یا Edge) نصب و پیش‌فرض کنید، یا PDF را باز و دستی چاپ کنید.
- **فونت فارسی در PDF:** فونت وزیرمتن داخل برنامه است و نیازی به نصب ندارد.
