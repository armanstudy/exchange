# راهنمای نصب و ساخت «LENJ Exchange» روی ویندوز

این پوشه یک نصب‌کنندهٔ «یک‌کلیکی» دارد که همهٔ ابزارهای لازم را روی ویندوز ۱۰ یا ۱۱ نصب می‌کند و برنامه را می‌سازد.

## ۱. دریافت کد

یکی از دو روش زیر:

- **دانلود ZIP:** در صفحهٔ GitHub پروژه، شاخهٔ `cursor/lenj-exchange-foundation-e31a` را انتخاب کنید، روی دکمهٔ سبز **Code** و بعد **Download ZIP** بزنید. فایل را با راست‌کلیک > **Extract All** از حالت فشرده خارج کنید.
- **git clone** (اگر Git دارید):

  ```
  git clone -b cursor/lenj-exchange-foundation-e31a <آدرس-مخزن> LENJ-Exchange
  ```

## ۲. اجرا

1. به پوشهٔ `installer\windows-setup` بروید.
2. روی فایل **`Install-Prerequisites.cmd`** دوبار کلیک کنید.
3. در پنجرهٔ UAC روی **Yes** بزنید (اسکریپت به دسترسی مدیر نیاز دارد).
4. صبر کنید تا کار تمام شود. بار اول، بسته به سرعت اینترنت، ممکن است ۱۰ تا ۳۰ دقیقه طول بکشد.

## ۳. چه چیزهایی نصب می‌شود؟

فقط ابزارهایی نصب می‌شوند که روی سیستم شما **نیستند**:

| ابزار | کاربرد |
|---|---|
| Git for Windows | دریافت و به‌روزرسانی کد |
| .NET 8 SDK | ساخت و اجرای برنامه |
| Inno Setup 6 | ساختن فایل نصب (`Setup.exe`) |

نصب از طریق `winget` انجام می‌شود و اگر `winget` نباشد، فایل‌ها مستقیماً از سایت رسمی سازنده دانلود می‌شوند.

بعد از نصب، اسکریپت برنامه را به‌طور خودکار می‌سازد، تست‌ها را اجرا می‌کند، نسخهٔ نهایی را منتشر می‌کند و فایل نصب را می‌سازد.

## ۴. خروجی‌ها کجا هستند؟

- **فایل اجرایی برنامه (EXE):** `artifacts\publish\` در پوشهٔ اصلی پروژه
- **فایل نصب (Setup.exe):** پوشهٔ خروجی Inno Setup (مسیر دقیق در خلاصهٔ پایانی نوشته می‌شود)
- **فایل گزارش:** `%TEMP%\lenj-setup.log`

در پایان، پوشهٔ خروجی به‌طور خودکار در File Explorer باز می‌شود.

## ۵. گزینه‌های پیشرفته (اختیاری)

اگر فقط اسکریپت را دارید و کد را ندارید، آدرس مخزن را بدهید تا در `Documents\LENJ-Exchange` دریافت شود:

```
Install-Prerequisites.cmd -RepoUrl https://github.com/<owner>/<repo>.git
```

- `-Branch <نام>`: انتخاب شاخه (پیش‌فرض: `cursor/lenj-exchange-foundation-e31a`)
- `-NoBuild`: فقط ابزارها نصب شوند و برنامه ساخته نشود

## ۶. رفع اشکال

- **winget پیدا نشد:** مشکلی نیست؛ اسکریپت ابزارها را مستقیم دانلود می‌کند. اگر winget را می‌خواهید، **App Installer** را از Microsoft Store نصب یا به‌روزرسانی کنید.
- **پیام SmartScreen («Windows protected your PC»):** روی **More info** و بعد **Run anyway** بزنید. اگر فایل از اینترنت دانلود شده، می‌توانید با راست‌کلیک > **Properties** گزینهٔ **Unblock** را هم بزنید.
- **آنتی‌ویروس:** بعضی آنتی‌ویروس‌ها اجرای اسکریپت PowerShell یا فایل EXE ساخته‌شده را مسدود می‌کنند. موقتاً پوشهٔ پروژه را در فهرست استثنا قرار دهید.
- **اینترنت یا پروکسی:** دسترسی به `github.com`، `dot.net`، `nuget.org` و `jrsoftware.org` لازم است. اگر از پروکسی یا VPN استفاده می‌کنید، مطمئن شوید که این سایت‌ها باز هستند. خطای `restore` معمولاً یعنی اتصال به `nuget.org` برقرار نیست.
- **اجرای دوباره بی‌خطر است:** ابزارهایی که قبلاً نصب شده‌اند دوباره نصب نمی‌شوند. اگر مرحله‌ای ناموفق بود، بعد از رفع مشکل دوباره روی `Install-Prerequisites.cmd` دوبار کلیک کنید.
- **مشکل دیگر:** فایل `%TEMP%\lenj-setup.log` را برای پشتیبانی بفرستید. (کلید `Win+R` را بزنید، عبارت `%TEMP%` را بنویسید و Enter بزنید.)
